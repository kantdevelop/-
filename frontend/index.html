View Once Bot

A small bot that downloads View Once media sent to it and saves the copies in its own chat. No reply is sent to the sender.

How it works

  • Link a phone account to the bot (see below).
  • Anyone sends a View Once photo/video/audio to the bot's account.
  • The bot downloads it and sends it back into the bot account's own chat.
  • You watch it there; it is saved as regular media.

Deploy it

  1. Run the bot locally: cd viewonce-bot && npm install && npm start and scan the QR with WhatsApp.
  2. Scan the printed QR code with WhatsApp → Settings → Linked devices → Link a device.
  3. Push this repo to GitHub; deploy it on Vercel for the frontend page above.
Keep the process running to receive View Once media; the QR code appears in the terminal each time it pairs or reconnects.
